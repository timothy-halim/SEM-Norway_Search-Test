# SEM-Norway_Search-Test
Short sample to demonstrate working code snippet and YouTube API key.

1. Visit https://console.cloud.google.com/ and start a new project.
2. Under "APIs & Services", go to "Enabled APs & Services", then enable the YouTube Data API key.
3. Under "APIs & Services", go to "Credentials", then generate an API key.
4. Add "YouTube Data API" in the "Select API Restrictions", then add additional key restrictions to scope the key properly.
5. Copy the API key.
6. Use the script listed in this directory and replace the API_KEY with your generated API key. Edit your channel ID if needed.
7. Copy the code and script into a page on Wordpress (or whichever application).
8. Load the page and search! Keep in mind it is limited to 100 searches a day for the free version.
